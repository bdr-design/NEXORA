التوسع يمنح قدرة تشغيلية بعد تجهيزها، لا يولّد دخلًا عند شراء اسم شركة.
مليون أصل هدف النظام، لكن كثرة العناصر ليست بديلًا عن عمق الوظيفة. نبدأ
بدورة طيران صغيرة كاملة، ونثبتها قبل تقديم صناعة أخرى. الأقسام أدوات لعمل
حقيقي؛ لا تُنشأ قوائم شركات أو وحدات إدارة لمجرد توسيع الشاشة.

في الذاكرة. لا يثبت ترخيص شركة أو طاقمًا أو وقودًا أو صيانة أو رواتب أو
حفظًا إنتاجيًا. R005 fixture ليس مليون طائرة واقعية أو اقتصادًا مكتملًا.

## المال والوثائق والموارد

كل مبلغ بعملة ثابتة ووحدات صغرى وعدد صحيح مع تحقق overflow. لكل كيان دفاتر
وجانب اقتصادي محدد. التمويل والتدفق النقدي والربح أرقام مختلفة. تحويل رأس
مال من القابضة لتابعة لا يزيد دخل المجموعة. التحصيل والاسترداد والتسوية
يحتاجان معرّف طلب ووصل دائمين؛ إعادة الإرسال بعد انقطاع لا تضاعف الأثر.
توكن R004 المحلي لا يُرقّى تلقائيًا إلى هذا الضمان.

| حدث مقترح | معنى اقتصادي | ما يظهر للاعب |
| --- | --- | --- |
| تحصيل حجز قبل تقديم الخدمة | نقد مقابل التزام خدمة/دفعة عميل؛ لا إيراد مكتسب بعد | مبلغ محصّل وحق عميل والرحلة الموعودة |

| تحصيل فاتورة مستحقة | نقد مقابل خفض المستحق؛ لا اعتراف ثانٍ بالإيراد | مستحق قبل/بعد ووصل تحصيل |

| استهلاك وقود/مواد | انخفاض مخزون مقابل تكلفة خدمة؛ تسوية المورد مسار مستقل | كمية متاحة ومحجوزة ومستهلكة وأمر الشراء |
| عمل الموظف | استحقاق تكلفة وأجر؛ الدفع يخفض التزام الراتب | عقد وفترة عمل واستحقاق ودفع؛ عدم الدفع لا يمحو التكلفة |
| استخدام طائرة مؤجرة | التزام العقد واستحقاق الفترات مع أثر نقد عند الدفع | مدة وتكلفة وإيجار مستحق ومدفوع؛ إنهاء أو رد أصل ليس زرًا مجانيًا |
| صيانة | أمر عمل ومواد وساعات وخدمة فعلية وتصنيف تكلفة وفق السياسة | سبب منع تشغيل وموارد وموعد فحص وإطلاق |

هذا اقتراح اقتصاد اللعبة، وليس دليل امتثال محاسبي أو قانوني. التوسع في
ضرائب وعملات وائتمان وشركات بنكية يحتاج عقدًا وبحثًا وقبولًا مستقلًا. لا
تُضاف تلك الخيارات حتى تنفذ دوراتها. الفواتير والإيصالات والشيكات والحوالات
الواردة والصادرة لها حالات إصدار/اعتماد/تنفيذ/رفض/تسوية/إلغاء وارتباط بالأصل
التجاري. إثبات تحويل أو صورة شيك لا يؤكد تسويةً بمفرده. الأصل الإعلامي
خارج hot state؛ رابط integrity واسترجاع كسول مع بيان ملف مفقود/تالف.

مثال تصميم معلن:100 مقعد بسعر500 وحدة صغيرة، تحصيل50,000 قبل الرحلة.
يظهر50,000 التزام خدمة حتى تقديمها. fixture وقود18,000 وخدمة أرضية4,000
وأجور مستحقة6,000 واحتياطي تكلفة صيانة2,500 وتكلفة أخرى1,000، بإجمالي31,500
لهذه الخدمة؛ مساهمة18,500 قبل أي تكاليف أخرى يحددها العقد. النقد النهائي
يعتمد على المبالغ المدفوعة فعليًا. ليست هذه أسعارًا واقعية مقاسة أو نموذج
جدوى. لا تُحسب أرباح القابضة بمجموع تحويلات شركاتها، ولا يُستنتج الربح
من حركة نقد واحدة.

## الواجهة والسلاسة

الواجهة تشرح حالة العملية ومواردها والتزاماتها والسبب التالي المحدد. تظهر
حالة واحدة مع الوقت المنفذ فعليًا. لا لوحات تحمل أرقامًا وهمية لمليون أصل،
ولا شركات زخرفية أو خيارات معلنة بلا دورة مقبولة. التصور البصري الحالي
لقراءة حالة رحلة ونتيجتها فقط؛ لا أزرار تنفيذ أو قوائم أقسام غير منفذة.
بعد قبول وظائفها، كل أمر واجهة يطابق انتقالًا بعقده ويرفض الحالة القديمة
بسبب واضح؛ الضغط لا يتجاوز تحقق المجال.

الاستعلام يعيد صفحة محدودة أو صفًا أو ملخصًا محفوظًا تراكميًا. لا مسح N
لكل search أو scroll أو touch أو frame. لا حفظ/صور/ترتيب جدول مليون صف على
MainActor. اختيار أصل واحد لا يوقظ جميع الأصول. الخريطة تستهلك projection
محدودة بالمساحة المرئية؛ لا تُستخرج الحالة الاقتصادية من الرسم. التجميع
البصري لا يحذف كيانات/حقوق من الاقتصاد. قراءات الواجهة versions منفصلة
عن writer mutable state، وتظهر actual simulated time/backlog بوضوح.

ميزانية الأداء الحاليةR005 ثابتة. ميزانية العرض والجهاز تحدد وتُقبل لاحقًا؛
قبل كل إضافة تُقارن زمن advance/service/WAL/writer/loop والتخصيصات والذاكرة
والأحداث المنفذة، ثم frames/input/thermal على الجهاز. ضغط العرض يمكنه خفض
تفاصيل مرئية؛ لا يخفض الدقة الاقتصادية أو يحذف payroll أوmaintenance أوsave.

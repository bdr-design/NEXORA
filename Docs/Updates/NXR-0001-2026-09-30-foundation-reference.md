Date: 2026-09-30

## Purpose
Create the first authoritative NEXORA foundation in its independent repository and make the repository itself the continuity source for architecture, execution rules, product requirements, performance targets, diagnostics and future update history.

## Added
- Clean-room technical independence from the previous game.
- Strict no-patch-first working method.
- Very-high-effort agent gate for sensitive work.
- Stop-and-handoff rule before context degradation.
- Master architecture/engine/state contracts.
- Discrete-event and multi-rate simulation direction.
- Data-oriented hot-path direction.
- Incremental persistence direction.
- Diagnostics/black-box as a foundation subsystem.
- Thermal/performance governor direction.
- Metal-backed high-density rendering direction.
- Capability-based enterprise architecture.
- Financial document requirements: incoming/outgoing transfers, cheques/images, transfer proofs, receipts and audit linkage.
- Progressive 1k/5k/20k/50k/100k scale gates.
- Real source-tree skeleton.
- Update/build/release traceability policy.

## Product commitments
20k fully functional assets is the minimum acceptance gate. 100k is the architecture design target. Smoothness and sustainable thermals take priority over wasteful continuous work. New industries must not require kernel rewrites.

## Technical status
No gameplay engine/runtime performance claim is made by this update.

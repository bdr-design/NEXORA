# Roadmap & Exit Criteria

Progress is evidence-gated, not calendar-promised.

## Stage 0 — Repository/contracts
Architecture, ownership, diagnostics, persistence, performance budgets, test matrix, updates/daily/continuity. Exit: reference versioned and accepted.

## Stage 1 — Core scale kernel
State Kernel, Transactions, Clock, Scheduler, Job System, determinism, scale harness, diagnostics. Exit: correctness + synthetic 100k measurements with no architectural blocker.

## Stage 2 — Persistence/read models
Incremental durable storage, recovery, projections/indexes, document-store skeleton. Exit: large save/query/load; no main-thread save stall; recovery proven.

## Stage 3 — Enterprise platform
Organization hierarchy, capability registry, Finance/Treasury baseline, HR, Sales, Procurement, Inventory. Exit: generic company composition without closed type switches.

## Stage 4 — World/economy
Geography, currencies/time, demand cells, markets/macroeconomy. Exit: deterministic scalable regional simulation.

## Stage 5 — Aviation
First full stress industry across assets, routes, schedules, finance, HR/crew, maintenance, demand and map. Exit: end-to-end gameplay + scale tests.

## Stage 6 — Metal map / polished UI
Spatial index, LOD, clustering, route buffers, read-model screens. Exit: smooth real-device interaction under scale.

## Stage 7 — Full 20k acceptance
Correctness, persistence, p95/p99, thermal soak, diagnostics proof.

## Stage 8 — 50k/100k architecture validation
Optimize only measured bottlenecks. Exit: documented 100k benchmark and no hidden all-assets-per-frame design.

## Stage 9 — Industry expansion
Automotive, dairy, mobile devices, maritime, road and others through capability/industry contracts.
